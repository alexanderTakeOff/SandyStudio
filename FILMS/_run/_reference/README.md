# Эталоны замера — клипы с заранее известным ответом

Ими калибруется и проверяется `scripts/run/measure-clip.ts`. Ответ по каждому известен из
опытов 25–26.08 (журнал — `docs/doctrine/generator-capabilities.md`), поэтому инструмент,
дающий на них другие числа, сломан — а не клип.

| Файл | Чем снят | Что показывает | Ожидаемые числа |
|---|---|---|---|
| `live-camera_selfie.mp4` | seedance img2vid с листа турнаранда, без звука | **ЖИВОЙ ход камеры**: рука несёт камеру, фон едет наравне с лицом | фон/лицо ≈ 1,10 · торс/фон ≈ 0,87 |
| `static-camera_poster.mp4` | kling ai-avatar на готовом кадре | **КАМЕРА СТОИТ** — норма для обращения в камеру, брак для селфи | фон/лицо ≈ 0,11 · моргания ≈ 7/мин |
| `carousel_defect.mp4` | seedance, промпт заказывал «фон качается» | **КАРУСЕЛЬ**: фон крутится вокруг неподвижного человека | фон/лицо ≈ 0,51 · **торс/фон ≈ 0,38** |
| `audio-ok.mp4` | сведение с `loudnorm=I=-16` | звук вещательного уровня | средний ≈ −20 дБ |
| `audio-too-quiet.mp4` | сведение без нормализации | «на телефоне не слышно» | средний ≈ −32 дБ |

**Почему они лежат в репозитории.** `live-camera_selfie.mp4` — единственный образец живого
хода камеры за всю историю прогонов, и он был получен случайно: модели подали картинку,
непригодную как кадр, и ей пришлось кадр сочинить. Повторить это дороже, чем хранить.
До 26.08 файл лежал во временной папке сессии, которую ОС вычищает.

**Правило: порог без эталона — число из воздуха.** Меняя порог в `measure-clip`, прогони
его по этой папке: эталон обязан остаться на своей стороне порога.
