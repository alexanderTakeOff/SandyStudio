# Pragmatico Manifesto — брендинг канала

Заведено шоураннером канала 2026-07-27. Директор проверяет по заполненному и правит.

## Что где живёт (источники правды)

| Что | Где | Кто читает |
|---|---|---|
| Оверлей / описание / теги шортсов, CTA, boilerplate | `channels.metadata.branding` (Supabase, key `PRAGMATIC`) | `webapp/lib/agents/branding.ts` — каскад series → channel → нейтрал |
| Категория / язык / made-for-kids при заливке | `channels.metadata.publish_defaults` | `publishDefaultsOf()` в channel-resolver |
| Формат по умолчанию | `series.metadata.delivery_targets = ['youtube_shorts']` | EREF (размер рефов), Storyboarder (вертикально-безопасный кадр), Animator (аспект) |
| Описание страницы канала, keywords, баннер | сам YouTube (`channels.update`, `channelBanners.insert`) | зритель |
| Язык публикации | Bible SS-S17 §17 «Язык публикации» | авторские агенты |

Править брендинг и publish-дефолты можно в UI: Settings → Channels.

## Визуальные решения

Типографический минимализм: почти чёрный фон `#101214`, тёплый белый текст `#EDEAE4`,
серая линия `#707780`, засечный шрифт с широким трекингом. Обоснование — Bible §24
(кинематографичный минимализм, сдержанная премиальность, визуальная тишина) и §24 прямо
запрещает копировать визуальный канон Sandy. Никакой генерации изображений: у канала
пока нет утверждённого визуального канона, а типографика его не предопределяет.
