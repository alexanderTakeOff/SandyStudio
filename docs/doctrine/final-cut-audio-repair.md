## Когда применять (премиса)

Ролик, где **видео идёт без звука** (seedance-fal-img2vid и подобные img2vid выдают немой
клип — проверено `ffprobe`: аудиопотока нет), а звуковая дорожка собирается на монтаже из
**речевых клипов (gen-speech) + отдельного амбиент-беда**. На стыках «голос кончился — кадр
ещё идёт» ухо слышит **дыру**: резкий провал уровня между фразой и паузой. Класс общий для
любой говорящей головы этого типа, не только для одной серии.

Премиса НЕ выполняется (не применять вслепую), если звук пишется в кадре единым трактом
или дорожка уже сведена компрессией на прошлой станции — тогда сначала замерь (ниже) и
реши по числу.

## Шаг 1 — ДИАГНОЗ замером, а не на слух

Достать локальный путь ката из кэша и померить профиль пауз. **«Дыра» — это НЕ тишина в
ноль**, поэтому `silencedetect` на −40 dB её может не увидеть; мерить надо ПЕРЕПАД.

```bash
# путь в кэше (localCacheAbsPath): C:/SandyStudio/FILMS/_media_cache/<S>/<E>/media/<файл>.mp4
F="…/final_cut-vNN.mp4"

# 1а. карта провалов голоса (перепад голос↔фон): порог −30 dB, дыра от 0.3с
ffmpeg -hide_banner -nostats -i "$F" -af silencedetect=noise=-30dB:d=0.3 -f null - 2>&1 | grep silence_

# 1б. шумовой пол в паузе против уровня голоса — узкими окнами volumedetect
for ss in <центр_паузы> <центр_голоса>; do
  ffmpeg -hide_banner -nostats -ss $ss -t 0.4 -i "$F" -af volumedetect -f null - 2>&1 | grep mean_volume
done
```

**Что читать в числах (эталон SS-S22-E03 v06, до лечения):**
- пол в паузах РОВНЫЙ (−48 dB, разброс < 1 dB) → амбиент однороден, выравнивать полы НЕЧЕГО;
- голос −16…−25 dB, пауза −48 dB → **перепад 25–32 dB ступенью за 0.3–0.5 с** — вот это и режет;
- на −40 dB провалов НЕТ → тишины в ноль нет, дефект чисто в перепаде.

> Ложные диагнозы, которые замер закрыл: «hiss речевого клипа громче фона» (нет — пол
> в паузах ровный) и «разный шумовой пол» (нет — амбиент один). Дефект — амплитудная
> ступень голос→пауза, а не разнородность шума. **Не лечи то, чего замер не показал.**

Цель лечения — числом: **перепад голос→пауза ≤ 12–15 dB** (вместо 25–32).

## Шаг 2 — ЛЕЧЕНИЕ: поднять floor паузы, голос не трогать (`compand`)

Раздельных исходников (голос/амбиент) на монтаже обычно уже нет — работаем с готовым
миксом. Инструмент — `compand` с кривой, которая **поднимает тихий уровень и почти не
трогает громкий**. Не `acompressor` (та жмёт сверху и makeup-гейном тянет floor и голос
вместе — перепад не сужается).

```bash
ffmpeg -y -i "$F" \
  -af "compand=attacks=0.05:decays=0.3:points=-70/-60|-48/-33|-30/-26|-16/-15|0/-2" \
  -c:v copy out.mp4
```

Читать кривую `points=in/out`: пауза `-48→-33` (+15 dB), голос `-16→-15` (не тронут). Между
ними плавно. `attacks/decays` размазывают подъём floor во времени → ступень-обрыв
превращается в мягкий переход, а не мгновенный провал.

**Подгонка под конкретный ролик:** двигай точку паузы (`-48/-33`) — это твой floor из шага 1
→ желаемый уровень. Держи floor так, чтобы перепад до голоса стал 12–15 dB. Выше −30 не
поднимай — фон паузы станет навязчивым шипением.

Проверка после (тот же скан volumedetect): floor паузы должен встать на заданное, голос —
на месте, `max_volume` не выше −0.5 dB (клиппинга нет).

Эталон SS-S22-E03: floor −48→−34, перепад 28→14 dB, разрывов нет (принято на слух).

## Шаг 3 — ДИСКЛЕЙМЕР в начало (если ролик синтетический)

Для demo/агитпроп-роликов плашка «Демонстрация технологии / Синтетический материал» обычно
уже стоит в КОНЦЕ. Если нужна и в начале — **переиспользуй существующую плашку из конца**
(тот же шрифт и вёрстка 1:1), не генерируй заново.

```bash
# найти границу плашки: кадры её однотонны и мелки (< ~70 KB против сотен KB видео)
ffmpeg -ss <t> -i "$F" -frames:v 1 probe.png   # бинарный поиск границы по размеру кадра

# продублировать сегмент плашки [t_старт..конец] в начало одним проходом concat
ffmpeg -y -i "$F" -filter_complex \
 "[0:v]trim=<t_старт>:<конец>,setpts=PTS-STARTPTS[dv];[0:a]atrim=<t_старт>:<конец>,asetpts=PTS-STARTPTS[da];\
  [0:v]setpts=PTS-STARTPTS[fv];[0:a]asetpts=PTS-STARTPTS[fa];\
  [dv][da][fv][fa]concat=n=2:v=1:a=1[v][a]" \
 -map "[v]" -map "[a]" -c:v libx264 -crf 18 -preset fast -c:a aac -b:a 192k out.mp4
```

Порядок операций: сначала лечи звук (шаг 2), ПОТОМ дублируй плашку — тогда сегмент плашки
несёт уже вылеченную дорожку. Сверь глазами первый кадр (Read) — должна быть плашка, не
остаток fade из предыдущего видео (бери `t_старт` за концом fade).

## Шаг 4 — Приёмка и след

- `measure-clip --type poster` — общий звук/полосы (для говорящей головы у микрофона камера
  стоит — `poster`, «камера стоит» БРАК тут неприменим, это про движение фона селфи).
- Повторить скан из шага 1 на выходе, предъявить перепад до/после **числом**.
- Судья на слух — Директор (перепад — прибор, «режет/не режет» — ухо).
- `register-media --kind cut` (версия вычисляется сама, max+1 — руками не задавать, D88).
  Рецепт (кривую compand + границы concat) вписать в `--desc` — промпт живёт с изделием.

## Инвариант (что переносится на подобные ролики)

1. Дыра между фразами у говорящей головы = **амплитудная ступень голос↔пауза**, не тишина
   и не разный шум. Ставит диагноз замер перепада, не слух.
2. Лечит **`compand` вверх по floor** (голос не трогать), цель — перепад ≤ 12–15 dB.
3. Дисклеймер — **переиспуск существующей плашки** через `concat`, не генерация новой.
4. Всё числом до/после; на слух судит Директор; рецепт — в `--desc` ассета.
