# Архитектура новой парадигмы — 30 строк

> Сформулирована 2026-08-07 по постановке Директора: «прежде чем менять архитектуру, её нужно
> сформулировать — в виде тридцати строк, а не тридцати страниц».
>
> Стоит на ратифицированном вердикте `content-factory-doctrine.md §VI` (путь C, доказан
> прогонами E35 · E36 · E37) и на порядке работ F4 из `cold-run-followup-tasks.md`.
> План реструктуризации — `docs/plans/paradigm-restructuring-plan.md`.
>
> **Тридцать строк — это предел, а не оформление.** Строка, которую нельзя проверить на живом
> эпизоде, в этот документ не входит. Добавляешь строку — удаляешь другую.

---

1. Четыре слоя: **База → Инструменты → Разум → Пульт**. Знание, Деньги, Learning — сквозные оси. Пятого слоя нет.
2. База = Postgres (52 миграции) + медиа-кэш + леджер. **Записи — истина, контекст — рабочая память.**
3. Формализуются **ВЕЩИ** (ассеты, статусы, деньги), не суждения; суждения живут в уме и в тексте ассетов.
4. **Ассет — единица истины.** Стадия выводится из префикса `file_type`; кирпич — ячейка `кадр × стадия`; тайминги — только в `VID-animatic`.
5. Требования стадий — **ОДИН источник**, объявленный как данные, не как код.
6. **Думает один:** Полина — единый ум на большой модели; смена модели — настройка UI, не архитектурное событие.
7. Один полный ум на произведение; сессия = эпизод; роль = **права + контекст + линза**, ум надевает и снимает. **Маленькие агенты исключены как класс.**
8. Исполняют **инструменты**: чистые функции вход→выход с самоописанием. Ум решает — тул делает — запись фиксирует.
9. Провайдеры живут в `lib/providers` под тулами. Отсутствующая способность (музыка, речь) **объявлена честно**, не спрятана.
10. **Реестр инструментария выводится из кода**; расхождение реестра с кодом ломает прогон. Ручных списков нет.
11. У ума полные руки: **глаза** (показ ассета картинкой), **перо** (запись ассета), **статус**, деньги, аудитория, публикация.
12. **«Сделано» — только с предъявленным артефактом**; скептик смотрит на ВЕЩЬ, не на отчёт.
13. Приёмка независима **чистотой контекста**, не другой моделью: слепой одноразовый ум смотрит и забывает — им же масштабируемся по длине окна.
14. **Отказ громкий и адресный**; тишина — худший класс отказа. Каждый тул либо отдаёт результат, либо кричит.
15. Черновик = ассет `DRAFT` рядом с `APPROVED`, без вытеснения; превью подтверждается честно — ум действительно смотрел.
16. **Гейты ДО траты:** резервация перед платным вызовом, запись факта — после. Мимо леджера денег нет.
17. Два ведра расходов: **работа и трение**; трение измеряется и давится первым.
18. Дефицитный ресурс — **обращения к человеку**: решения укрупняются, их число минимизируется.
19. **Хард-лимиты человека: публикация · LOCK · бюджет · режим.** Всё остальное ум решает сам.
20. Знание = **context + MD + промпты + скиллы**; ось скиллов — **РАБОТЫ**, не должности.
21. Квоты скиллов сняты — они были под маленькую модель; большой ум читает сколько нужно.
22. Маршрут один — `ss-run`: путь читается **ПЕРЕД** прогоном, не выясняется во время.
23. Learning = журнал прогона + сторожок + прибор **«прогон N против N−1»**; дискриминатор критик/производитель упразднён.
24. Память канала живёт (ось `channel_id`); долговечный исполнитель сведён к кронам — **расписание, не мышление**.
25. В коде **нет** reconcile / gate / state-matrix / next-events: оркестрация — мышление ума, а не кодовая начинка.
26. **Надёжность — простотой, не перепроверками:** минус ~60 000 строк; меньше кода — меньше хрупкости.
27. Пульт — существующая витрина по `APPROVED`-ассетам: инбокс решений с родословной · показ материала · «почему так» одним движением · вмешательство словом · деньги в момент решения.
28. Масштаб по объёму — параллельные сессии-эпизоды (**серия — параметр, не хардкод**); по глубине — слепые одноразовые умы.
29. От старого мира остаются только: база + миграции, медиа-кэш, леджер, провайдеры, кроны, скиллы, прямые инструменты.
30. **Весь путь новый; эталон работоспособности — живой эпизод, прошедший его целиком, а не зелёный билд.**
