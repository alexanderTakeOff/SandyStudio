## И3 — HeyGen: стоит ли ключа

**Да, но не сейчас.** Умеет: Digital Twin по 2–5 мин видео (наши 7 мин 4K — с запасом),
русский TTS + voice clone (Creator $29/мес), 9:16, свой фон (`background.type=video`) и
**WebM с альфа-каналом** — аватар ложится поверх нашего двора в ffmpeg. Проигрывает в
главном: аватар — плоский слой, **нет взаимодействия с мизансценой** (тени/окклюзия/свет
двора), ракурсы только из записи; вертикальный alpha-экспорт официально подтверждён лишь
для 16:9. Биометрия: consent-video обязателен, хранение до удаления+60 дней, обучение —
opt-out. Конкуренты (Synthesia/D-ID/Hedra/Argil/Captions) для нашего кейса не лучше.

## И4 — ВЕРДИКТ

**Победитель — (а) двухслойная fal-связка:** seedance (немой клип по канону эмоций) →
MiniMax clone-TTS (голос Директора) → липсинк (A/B: Kling против sync-3).
Почему бьёт (б) HeyGen: у нас мизансцена — конкретный двор, персонаж ВНУТРИ сцены; HeyGen
клеит слой. Почему бьёт (в) Veo 3: лицо пересобирается каждый шот и голос не наш — бьёт в
главное для сериала-клона. Цена эпизода по (а): ~$0.03 голос + $0.21–4 липсинк.
HeyGen — кандидат второй очереди для «говорящей головы к камере» (обращения, анонсы).

## И5 — Каким шотам липсинк НЕ отдавать

Профиль >~60° · рот перекрыт (рука/микрофон/волосы) · несколько лиц без кропа ·
шейк/быстрый пролёт камеры · контровой/мерцающий свет · вход <480p · стоп-кадр без
движения губ (для sync-2). **Очки Директора** (тонкая оправа, блик): документированно
держит только sync-3; Kling — только после теста на фронтальном ракурсе без блика.
Русский нигде не подтверждён замером → обязателен свой тест с шипящими/«ы»/быстрой речью.
