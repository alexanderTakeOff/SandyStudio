# E18 → FIX PLAN (исполняемый)

> Собран из `docs/analysis/E18-run-defects.md` (D1–D18 + диспозиции).
> Дата: 2026-07-08. Первый ЧЕСТНЫЙ прогон автономии (E18 «Sandy in the Airport-2», 14 шотов, 2.5ч).

## ВЫВОДЫ ИЗ ПРОГОНА (не история — суть)

1. **Пайплайн РАБОТАЕТ end-to-end.** 14 шотов, все картинки+видео APPROVED, final cut собран, опубликовано.
   Проблема НЕ в надёжности — в **автономии и стоимости**.
2. **Автономия низкая: аппрувы вёл Директор.** Mode 3 не делегировал одобрения Полине (68 аппрувов Директор
   vs 6 Полина). Артефакты (картинки/видео) никто визуально не утверждает автоматически (D16).
3. **Стоимость — это МОЗГ, не медиа.** ~$1.34/кадр и ~23 пробуждения мозга/кадр — только чтобы Полина
   реагировала на телеметрию (D17). Полина: $18.82 / 378 auto-react вызовов. **Не масштабируется** — на
   32-кадровом эпизоде $30-cap пробьётся.
4. **Один рычаг закрывает половину — МАТРИЦА утверждений** (терминально-триггерное продвижение + курируемый
   feed мозга): схлопывает и churn (D12), и firehose нуджей (D17).
5. **Дыра в учёте денег (D18):** интерактивный чат Полины не логируется и не капится — невидимый расход.
6. **Урок Тео:** 3 «критичных» находки (D8/D10/D11) оказались ложными — артефакты кривых выборок.
   Впредь верификация через `jobs`/counts/scorecard, не через хрупкий парсинг.

## БАКЕТ 1 — АППРУВ/СТЕЙТ-МАТРИЦА ⭐ (большой камень, закрывает D3·D5·D9·D10·D12·D13·D16)

**Инвариант:** следующая стадия триггерится ТОЛЬКО на терминальную/APPROVED-ячейку, НИКОГДА на внутренний
вердикт критика. Код (мышца) молча проглатывает каждое событие и двигает пайплайн; мозг просыпается по
ИСКЛЮЧЕНИЮ (решение / HALT / застревание). Это reconciler/state-matrix, сделанный ПРАВИЛЬНО.

- **D3** — downstream (EREF) на `STB-APPROVED`, не на `REV-world_check`.
- **D12** — terminal-guard: не переавторить план после его APPROVED (был SH11 v04/v05 → деньги).
- **D5** — убрать «пилоты» как класс; универсальный **стоп после первых 2** (seq: 2 реф; par: 2 реф+2 видео)
  → Director-гейт. (форма стопа в parallel — уточнить: один комбинированный стоп.)
- **D9 / D13 / D16** — в Mode 3 артефакты (реф/картинка/видео) утверждает Полина/агент **с реальным просмотром**
  или авто при PASS — не Директор вручную. Reconciler привязан к **governance-режиму**, не к env-флагу;
  критик PASS→advance, FAIL→Полина, ≥cap→Полина(Mode 3)/Директор.
- **D10** — само-детекция столлов = фича матрицы («ячейка APPROVED сверху, артефакта нет N мин → всплыть»).

## БАКЕТ 2 — ДЕНЬГИ / ЭКОНОМИКА МОЗГА (D17 · D18)

- **D17** — инвертировать подписку. **Агент проанализировал (2026-07-08), политика ГОТОВА.** Это ДВА
  firehose, не один:
  - **Gate A (инъекция, без LLM):** DB-триггер `tg_inject_activity_event_into_concierge`
    (`migrations/0033…sql:33-42`) + зеркало `lib/concierge/ambient-events.ts:40-53` — пишет `role:system`
    на каждый whitelisted event → **438 инъекций**.
  - **Gate B (платный notify, LLM):** `lib/api/event-actionable.ts:22-40` `ACTIONABLE_EVENT_TYPES` →
    `pa/notify-needed` → auto-react loop (до 6 раундов, каждый billed) → **378 вызовов / $18.82**.
  - **⚠️ Находка:** director-own suppression СЛОМАНА (`0033…sql:74-79`, `director_id≠actor`) → **твои же
    68 approval_granted + 46 manual_trigger вернулись ~114 платными вызовами** — крупнейшая платная категория.
  - **Фикс (чистое вычитание, ~3 правки):**
    1. Gate B allow-list → только 8 MUST-WAKE: `agent_failed, approval_revision, approval_rejected,
       blocker_raised, decision_requested, input_requested, budget_threshold_reached, canon_extension_proposed`.
    2. Gate A → выкинуть `agent_started / approval_granted / manual_trigger`; `agent_completed` оставить как
       контекст (не будит), свернуть в дайджест.
    3. `exec-pa-react.ts:67-77` — fail-dedup по `(actor, asset_id)` (9 повторов VANIM → ~3-4).
    4. (опц.) Phase-2 дайджест — cron ~20мин, один rollup-turn «12 завершено, 5 одобрено, 2 pending».
    5. **Пере-взвести фенс:** `CONCIERGE_AUTO_REACT_MAX_CALLS` 500→~40, `concierge_cap_usd` →~$3 (курирование
       = основной контроль, фенс = только на регрессию).
  - **Результат:** 438→**~30 инъекций**, 378→**~20 платных**, $18.82→**~$1.30 (14×)**. Все failure/decision/
    revision/budget-события будят Полину мгновенно — реактивность сохранена.
- **D18** — вызывать `recordConciergeCost(source:'chat')` из интерактивного `/api/concierge/chat` +
  включить его в cap/circuit-breaker (сейчас видит только auto-react).
