### Ш11 · РАСХОЖДЕНИЕ НАЙДЕНО: кто такой «ведущий ум» — 12:43

Директор: «ты работаешь директором. Точка, директором. А Полина и есть этот центральный
разум? Из-за чего появилось расхождение — этого нет в парадигме, не реализовано в коде,
или ещё что-то?»

**Ответ — три слоя, все проверены по источникам, не по памяти.**

1. **В постановке не назначен исполнитель.** `content-factory-doctrine.md §4` говорит
   «один полный ум на произведение: один ведущий **на сериал**, **рабочая сессия на
   эпизод**»; `cold-run-brief.md`: «Директор решает тему, потолок, публикацию — **всё
   остальное за ведущим умом**». Форма описана, **имя не названо ни разу**. Полина в
   парадигменных документах не упоминается вообще. По умолчанию ведущим умом оказывался
   тот, кто писал документ, — сессия Claude Code. Все три прогона (E35–E37) вёл я, Полина
   была обойдена целиком.
2. **В коде Полина — диспетчер, а не ум.** Её инструменты (`lib/concierge/tools/`):
   `dispatch`, `fanout`, `conductor`, `pipeline`, `cast`, `storyboard`, `eref`,
   `eref-execute`, `vgen-execute`, `animator`, `visual-critic`, `wait-for-pickup`. Все
   глаголы — **запустить роль и дождаться**. Инструмента «напиши сценарий сам» у неё нет:
   есть «запусти EXEC-SW». То есть по коду она голова СТАРОЙ модели — центр конвейера из
   двадцати ролей, а не замена ему.
3. **И окно у неё чужое.** Доктрина обосновывает один ум тем, что длинный контекст держит
   бриф, сценарий, раскадровку, канон и историю правок **разом**. `EXEC-CONC` по CLAUDE.md §5
   — OpenAI, `OPENAI_MAX_OUTPUT_TOKENS=8000`, реакция ход-за-ходом. Произведение целиком
   она физически не держит.

**Итог: «Полина = центральный разум» — ожидание Директора, которого нет ни в постановке,
