# E32 — инвентаризация участия Директора

**Дата:** 2026-07-28 · **Режим прогона:** Mode 2 · **Ветка:** `claude/showrunner-pragmatic-c77b43`

## Зачем

НЕ «проверить Полину». Полина — руки, не предмет.

Цель Директора — фабрика, где его участие сведено к идеальному минимуму.
Значит вопрос прогона один: **где машина всё ещё требует человека — и какие из
этих точек она могла бы забрать себе.**

Выход прогона — не «работает / не работает». Выход — **список того, что можно
выкинуть из участия Директора.**

## Форма

Я иду за Директора через Полину: от выбора темы до подхода к дизайнеру
референсов. На каждом человеческом действии — запись и корзина.

### Три корзины

| Корзина | Что это | Что с ней делать |
|---|---|---|
| **A — суждение** | Требовало настоящего решения: вкус, риск, деньги, зритель | Оставить человеку или построенному критику |
| **B — формальность** | Нажал не думая, решение было предопределено входными данными | **Кандидат на удаление.** Это и есть добыча прогона |
| **C — упор** | Не смог решить за Директора вообще | Настоящий hard limit, назвать явно |

### Почему Mode 2, а не 3

Mode 3 проглатывает творческие гейты молча — корзина B становится невидимой.
Инвентаризация требует, чтобы **каждая точка всплыла**, даже пустая. Mode 2 здесь
не осторожность, а прибор. Mode 3 — это уже применение результата, не его сбор.

## Правила прогона (жёсткие)

1. **Всё через Полину.** Сам в БД, скрипты, API не лезу. Если что-то делается
   только руками — это находка, а не обход.
2. **Код не правлю.** Единственное исключение — tool-обёртка над операцией,
   которая **уже есть** на сервере. Нет операции в коде = дыра пайплайна:
   в журнал, не строю, иду дальше.
3. **Пайплайн не чиню.** Сломалось — записал, пошёл дальше.
4. **Стоп перед первым платным вызовом** (генерация картинок, EXEC-EREF).
5. **Rebuild** — только durable через файл на десктопе Директора.
6. Публикация · LOCKED · бюджет · смена режима — не трогаю ни в каком виде.

## Что пишу на каждом гейте

Что решал · на чём основал · было ли решение предопределено входом · корзина.

## Чего этот прогон НЕ делает

Честный замер себестоимости (fair smoke) — там Полина выключена и код заморожен.
Здесь ровно наоборот. Замер остаётся долгом, отдельным прогоном.
