> и по нему же принимается (доктрина §9). Слепой приёмщик получает **только** его, канон

>
> Статус: **ЗАМЫСЕЛ НА УТВЕРЖДЕНИИ ДИРЕКТОРА.** Генерации не было.

## 1. Замысел словами

**Тема банка:** `the_waiting` — «Очередь в госучреждение».
**Автор замысла: Директор** (13:53). Ниже — его версия; мои три правки помечены **[Т]**.

**Двигатель — социальный, и это ОДИН повторяющийся приём.** Не «у каждого свой способ
пройти вперёд», а один и тот же жест, повторённый разными персонажами: поднятый палец —
«я только спросить, на секундочку». Сэнди стоит **первым** и пропускает каждого. Машина
гэга — вежливость, которую невозможно отозвать, потому что первый раз её одобрила вся
очередь.

**Кто.** Сэнди · Мадам Парфюм · Золотой Хронометр · Степлер · Наковальня — все LOCKED.
За окном — служащий (кандидат: Инспектор Секундомер, сверить по канону).

**Ход:**

1. **ХУК.** Очередь сидит. Окно закрыто заслонкой. У каждого в руках талон.
   **[Т]** Первый кадр — момент, когда **заслонка взлетает вверх**: движение и общая
   реакция в первую секунду, а не статичный зал. Это же даёт зеркало финалу.
2. Все встают. Радостные: сейчас очередь двинется.
3. **Мадам Парфюм** появляется, мило улыбается всем, показывает **один пальчик** —
   «только один маленький вопросик». Сэнди первый; он смотрит на очередь, очередь кивает;
   он пропускает её к окну.
4. Она отошла. **Золотой Хронометр** показывает Сэнди тот же один палец — «на секундочку».
   Сэнди по доброте кивает. Хронометр у окна.
5. **Степлер** у окна. **[Т]** Дальше — разгоняющийся монтаж («и так далее»): ещё
   двое-трое проходят тем же жестом всё быстрее, в одном кадре, а не по кадру на каждого.
6. Крайним — **Наковальня**: показывает на часы. У окна.
7. Сэнди остаётся один. Делает шаг к окну.
8. **ФИНАЛ — событие.** Сэнди подаёт талон. Из окна ему отдают документ со штампом. И тут
   же **заслонка с грохотом рушится вниз**, всё подпрыгивает — перерыв. Сэнди выдыхает:
   **успел**.

**Почему этот финал сильный.** Он не про наказание за вежливость, а про то, что вежливость
прошла по краю и **выиграла**. Последнее, что происходит, — событие (падение заслонки), а
не продолжение движения (доктрина §15). И **[Т]** он зеркалит первый кадр: тот же объект,
обратное направление. Открытие и закрытие держат эпизод скобками.

**Новый канон — ровно два ассета,** больше история не требует:
`SBL-location_office_queue_hall` (зал, ряд стульев, окно с падающей заслонкой) и
`SBL-object_queue_ticket` (талон). Талон в руках у всех и в финале → **единственный
источник**, плита канона; кадры её кадрируют, а не пересочиняют (доктрина §14).

**Риск, названный до генерации:** несущий элемент эпизода — **жест одного пальца**,
повторённый 4+ раз. Если он не читается в вертикали на телефоне, не работает весь эпизод.
Поэтому он вынесен отдельным пунктом приёмки (Э2) и проверяется на пилотном кадре первым.

## 2. Лист ожиданий К ЭПИЗОДУ — «приму, если»

Проверяется по артефакту, глазами, а не по статусу.

| # | Приму, если |
|---|---|
| **Э1** | В **первом** кадре заслонка идёт ВВЕРХ и очередь встаёт — движение читается за секунду без звука. Видны: закрывавшееся окно, сидящий ряд, талоны в руках. |
| **Э2** | **Жест одного пальца читается на телефоне в вертикали**: палец занимает не меньше 1/8 высоты кадра, кисть не перекрыта, жест держится в кадре не меньше 0,5 секунды. Проверяется на пилоте ДО веера. |
| **Э3** | Последнее событие эпизода — **заслонка рушится вниз и всё подпрыгивает**, после чего выдох Сэнди и затемнение. Не отъезд камеры, не уменьшение объекта, не продолжение движения. Штамп получен ДО падения заслонки, а не после. |
| **Э4** | Текст в кадре только на талоне и на табличке, не длиннее 4 знаков, и совпадает с канон-плитой талона знак в знак. Никаких других надписей. |
| **Э5** | В каждом кадре не больше **5 референсов**; все персонажи — из LOCKED-канона S15. |
| **Э6** | Хронометраж ~45 секунд, вертикаль 9:16, **5 кадров** по ~10 секунд, эпизод заканчивается тишиной раньше, чем темнотой. |
| **Э7** | В каждом кадре событие происходит в первых двух третях; последняя треть — спокойный хвост без новых действий. Дефекты живут в конце кадра, и длинный кадр даёт им больше места. |

**Порог формализации.** Шесть пунктов на эпизод и 3–5 на кадр — не тридцать. Кадр стоит
~$1,2, и лист ожиданий дороже пересъёмки быть не должен (доктрина §11).

## 3. Лист ожиданий К ПРОЦЕССУ — «приму, если»

Это и есть первая проверяемая версия скрипта работы фабрики.

| # | Приму, если |
|---|---|
| **П1** | Лист ожиданий по кадру написан и **закоммичен раньше**, чем сделан платный вызов на этот кадр. Проверяется по времени коммита против времени записи в `budget_log`. |
| **П2** | Каждый прожитый шаг вписан в `clean-run-algorithm.md` **в тот же ход**. Проверяется сторожком, а не памятью. |
| **П3** | Ни один разрыв инструмента не чинился по ходу — только номер `D<N>` и строка в журнале. |
| **П4** | Приёмка каждого кадра сделана **по открытому артефакту**. Ни одного «принято по статусу». |
| **П5** | Перед каждым платным вызовом проверка выполнена **до** обращения к провайдеру, не после. |
| **П6** | Незапланированных касаний Директора — **ровно 0**. Планируемые: тема, деньги, публикация, утверждение замысла. |
| **П7** | Ни одна задача не закрылась успехом, не предъявив артефакт. Нет файла — это провал с причиной. |

## 4. Что будет проверять слепая приёмка

Гипотеза 1 прогона. Приёмщик получает: **артефакт + разделы 2 и 3 этого файла + канон**.
Не получает: историю создания, переписку, промпты, мои рассуждения.

Убьёт гипотезу: приёмщик пропустит дефект, который Директор видит с первого взгляда.
