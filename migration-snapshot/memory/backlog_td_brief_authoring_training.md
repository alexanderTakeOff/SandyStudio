# TD — brief-authoring training (триггер: ПОСЛЕ E09 final cut)

Director-решение 2026-06-13: фиксы делаем после финального ката E09 (порядок:
E09 до финала → потом TD). Анализ родился из сравнения двух брифов E09:
агентский (тонкий) vs Director-правленый (эталон).

## Мета-урок
LLM по умолчанию АБСТРАГИРУЕТ (гладкий связный пересказ). Комедия требует
обратного — конкретики и избыточной генерации. «Делать лучше» = явно ломать
инстинкт абстракции, вшив принуждение к конкретике в skill-файлы. Само не чинится.

## Суть разницы (агент vs Director-бриф E09)
Агент комедию ОПИСАЛ (прилагательные: «increasingly desperate», «escalating»);
Director её СКОНСТРУИРОВАЛ (60 пронумерованных глагольных гэгов + закон, их
порождающий). Бриф агента = logline раздутый по разделам, ноль самих гэгов,
убит панч, нет физики песка, добавлен мусор («oppressive lobby, walls closing
in»). Director: банк 60 гэгов, закон «нет пустого бита», физика песка работает,
эмоц-лестница названа, финал+тон определены, геометрия камеры задана, guardrails
негативами, минимализм фокуса; + перенёс действие ВНУТРЬ кабины (6-кнопочная
панель + двери-партнёр) вместо слабой «одной кнопки в холле».

## 8 правил брифа (абстрактно, по РОЛИ — не про лифт; skill-creation discipline)
1. **Закон «нет пустого бита»**: каждое действие героя над объектом даёт видимую
   реакцию (правильную-не-так / запоздалую / чрезмерную / издевательски-точную).
   Никогда «сделал — ничего». Это гэг-ДВИЖОК, не правило стиля.
2. **Перечисляй, не характеризуй**: gag-bank из N пронумерованных конкретных
   гэгов (глагол + объект + исход). Метод over-generate N → отобрать лучшие.
   Прилагательные про эскалацию запрещены как ЗАМЕНА гэгам.
3. **Физика героя — источник гэгов**: определяющее физ-свойство персонажа
   порождает ≥X конкретных гэгов (+ правило возврата в безопасную форму).
4. **Эмоц-лестница названа** по актам (уверенность→нетерпение→…→облегчение).
5. **Финал и панч определены, с тоном** (успех/провал/горько-сладко).
6. **Бриф кормит камеру**: геометрия сета (базовые виды) + нужные POV/крупные планы.
7. **Guardrails негативами**: что ИЗБЕГАТЬ (тон, стилизация, зависимость от звука,
   реальная опасность).
8. **Минимализм фокуса**: назвать что УБРАТЬ из кадра.

## Где вшить (train-personnel доктрина — код+skill один коммит)
- Новый skill `brief-authoring` (flavor: process) = 8 правил чек-листом + метод
  over-generate→select + **канонический worked-example = Director-бриф E09**
  (как `library-style-first` сделан образцом). Владелец — брифо-автор (Полина).
- EXEC-SW skill: «есть gag-bank → используй; нет → сгенерируй ≥N до драфта; не
  схлопывай гэги в прилагательные; сохрани панч+тон финала».
- EXEC-SB skill: «каждый шот несёт конкретный гэг из банка с видимой реакцией
  объекта; держи геометрию камеры; ноль пустых битов».
- EXEC-CREAD: добавить закон «нет пустого бита» явной проверкой (близко к
  object-causality в `readability-comedy-slapstick`, но сейчас не заворачивает
  за «нажал-ничего»).
- Канонический пример (полный текст Director-брифа E09) durable-станет, когда
  бриф ляжет в БД E09 как APPROVED SPC-brief (при запуске E09). До этого живёт в
  сессии 2026-06-13.
