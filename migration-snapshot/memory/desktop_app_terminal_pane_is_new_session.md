Урок 2026-06-10 (разбор путаницы с Директором, сессия «переключение режимов»):

- **Терминальная пиктограмма** в окне десктоп-приложения Claude Code открывает обычную командную строку рядом; `claude` в ней рождает **НОВУЮ сессию**. Одно окно визуально может содержать ДВЕ сессии: GUI-тело — одна, терминальная панель — другая. Это сбивало Директора («мастер-оркестратор» в GUI + я в его терминальной панели).
- **У живой сессии один локальный интерфейс.** Второй локальный терминал к той же сессии подключить нельзя. Единственный мульти-экран — `/remote-control` (зеркала через claude.ai: телефон/web; в сайдбаре сессия получает значок облачка ☁️). Запускать его надо В ТОЙ сессии, которой хочешь управлять удалённо.
- Сессии видят друг друга только через диск: стенограммы `~/.claude/projects/C--SandyStudio/*.jsonl`, планы `~/.claude/plans/*.md`, PLAN.md, память. Чужую сессию можно читать пассивно (tail её .jsonl), управлять — нельзя. Связано: [[orchestrator-master-session-paradigm]].
- CRD (PIN 557557) — запасной путь жать кнопки в любой сессии удалённо; laptop→desktop connect-тест ПРОЙДЕН 2026-06-10.
