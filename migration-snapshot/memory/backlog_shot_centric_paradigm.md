Director 2026-06-20: после удачного прогона — большой рефактор pipeline+UX. Системно сейчас навигация **executor-centric** (всё крутится вокруг исполнителя): кликнул реф-артиста → галерея; перещёлкнулся на композитора → галерея схлопнулась, контекст ушёл с глаз. Корень дискомфорта.

**Инверсия → shot-centric.** Дом = сетка видео-аниматика (большой экран, ячейка = кадр), генерится сразу как из раскадровки известно «сколько шотов». Единица работы — кадр, не исполнитель.

**Развилка-перелом (важно — не «аниматик вместо всего»).** До раскадровки работа цельно-эпизодная и линейная: кастинг→бриф→сценарий→борд — её на кадры не порежешь. Аниматик = точка перелома: там рождается shot-count, оттуда вниз всё параллельно и по-кадрово. Хребет эпизода остаётся stage-линейным до борда; сетка шотов — дом после.

**Плитка шота = живая ячейка состояния.** Пустая → тёмная + звёздный фон (зарезервированное место под несгенеренный видеошот, НЕ дырка; м.б. анимация). Пошла работа → плитка отражает фазу: дизайнер пишет план / критик меряет целостность / реф-артист рендерит / vgen. Клик → устойчивое **досье шота**, не исчезает при переключении (фикс executor-боли); правка + управленческие решения прямо там.

**Связь со slice 0.** Досье шота = единый version-editor (текущая работа, plan `workstation-reference-designerdesigner-r-twinkling-hamming.md`), scoped на артефакты одного кадра. Version-editor встраивается per-артефакт внутрь плитки — фундамент общий, не выброс.

**Поглощает 3 бэклога:** [[backlog_td_pipeline_full_process_surface]], [[backlog_eref_pipeline_node_spec]], [[backlog_td_artdir_breakdown_role]] + кастинг-перед-брифом (дешёвый структурный выигрыш, убивает фантомные локации by construction).

**Why:** текущая stage/executor-ось теряет контекст при каждом переключении; продукт — видеофрагмент, его естественная единица = шот, не агент. Shot-centric совпадает с тем, как Director реально думает о работе.

**How to apply:** делать ПОСЛЕ удачного прогона, слайсами (не big-bang): (1) сетка-аниматик-как-дом + живые плитки; (2) per-shot досье поверх version-editor; (3) кастинг-первым в порядке pipeline. Полную spec под `specs/` писать в самом рефактор-PR (нужен ===5===); этот файл — концепт-якорь. Текущий version-editor план не раздувать.
