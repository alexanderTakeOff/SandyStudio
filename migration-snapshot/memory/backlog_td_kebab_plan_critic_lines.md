**TD после прогона E16.** Директор (2026-07-05, E16 run) хочет усовершенствовать kebab-досье шота из «двух зон» в полноценную видимость всего процесса с рабочими кнопками. Это НЕ новая функциональность — весь функционал уже существует в системе, его нужно **вынести в kebab и правильно здесь обработать** (anti-additivity: переиспользовать существующие хендлеры generate/approve/re-video, не плодить новые).

**Сейчас:** kebab = блок References + блок Video (shipped `dd3bfe1`, см. [[backlog_kebab_video_reference_zones]]).

**Целевой вид — в ОБЕИХ зонах (References и Video) показать явные ЛИНИИ:**
- **Линия плана** — вывод Reference/Video Designer, каждая версия плана отдельной строкой.
- **Линия критика** — вердикт критика по плану, по версиям.
- **Линия ассета** — сама картинка (reference) / версия видео.

Так Директор видит весь путь: `Designer → план → Critic → Artist → картинка` (референсы) и `план → критик → видео` (видео).

**Кнопки на каждой линии/версии (двунаправленные, должны РЕАЛЬНО работать):**
- **Утвердить / Снять утверждение** (toggle) — на планах, критиках, картинках и видео. Обратный ход обязателен.
- **References зона:** добавить кнопку **«Сгенерить / Перегенерить»** напротив каждой версии плана и напротив каждой картинки, как только она появится. Сейчас у референсов такой кнопки НЕТ (у видео — есть). Функционал существует — вынести сюда.
- **Video зона:** на каждой версии линии видео кнопка **«Сгенерить видео»**; если видео уже сгенерено → опция становится **«Перегенерить видео»** и открывает широкий drawer с разными опциями пере-видео (этот drawer уже есть).
