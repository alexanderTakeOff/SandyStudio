Когда мне нужно **действие от Директора** (нажать кнопку, включить API, дать доступ,
принять решение, запустить что-то руками) — строка с этим требованием помечается
**яркой эмодзи в начале строки**. Не в конце абзаца, не в заголовке раздела — на
самой строке действия.

**Why:** Директор читает мои ответы по диагонали на скорости. Просьбы о действии
тонут в плотном техническом тексте и теряются — работа встаёт, а я думаю, что жду
ответа, тогда как он просто не увидел просьбу. Эмодзи — единственный якорь, который
цепляет глаз при беглом чтении.

**How to apply:** 🔴 для блокеров (без этого работа стоит), 🟡 для «нужно, но не
блокирует», 🟢 для подтверждений/выборов. Одна строка = одно действие. Если действий
несколько — каждое своей строкой со своей эмодзи. Стакается со сквозной нумерацией
`q<N>` — эмодзи ставится ПЕРЕД номером: `🔴 q6 — включи ...`.

Установлено 2026-07-21 (сессия HoG / планета Дистрибуция) после того, как просьба
включить API утонула в тексте.
