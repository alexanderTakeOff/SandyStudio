Директор (2026-07-21, q27): «пиши docs кратко плиз. очень кратко. caveman style —
especially work docs. I read very rare so you can write shortly».

**Why:** рабочие доки (handoff, планы, отчёты в docs/) Директор почти не читает —
длинный текст = потраченное время автора и нулевая конверсия. Читает он чат и PLAN.md.

**How to apply:** work-docs = телеграфный стиль: короткие строки, таблицы, никакой
прозы-обвязки. Полные формулировки — только в канонических местах (CLAUDE.md, скиллы,
спеки), где их читают агенты. Упомянутый «skill caveman» в текущем стеке не найден
(вероятно, в отключённой ECC-библиотеке [[harness_trim_skills_library]]) — принцип
применяется и без скилла.
