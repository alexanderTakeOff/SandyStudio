Director 2026-06-22 (E12 metadata «слабо»): EXEC-COPY (publicist) пишет аннотацию для кинофестиваля —
допускает, что зритель знает Сэнди, не сигналит «мультфильм», слабый SEO. Должен писать для ХОЛОДНОГО
незнакомца из поиска/ленты. Это не разовая правка текста — смена УГЛА скилла.

**Иерархия находимости 2026 (live research):** превью+заголовок (клик) → первые 100-150 симв описания +
watch-time → 3-5 хэштегов (≈+28% показов 48ч) → теги (почти ноль).

**5 принципов, которые публицист обязан принять:**
1. Веди универсальной СИТУАЦИЕЙ (боль), не персонажем — холодный зритель не знает Сэнди, но
   «телефонную зависимость» знают все; имя в хвосте-дескрипторе.
2. Первая строка описания = сниппет = онбординг = SEO-предложение (одно и то же); ключ в первых ~40
   симв, «что это (кто+формат+тема)» в 150.
3. Всегда штамповать формат: «Animated/Cartoon» + «No Words/Silent» (немое = глобальное преимущество,
   нет языкового барьера — ПРОИЗНОСИТЬ, не прятать).
4. Заголовок+превью берут клик; теги не весят; 3-5 хэштегов дают бонус.
5. Премиса протагониста = движок крючка («его время утекает буквально пока он скроллит» = триггер шеринга).

**Заголовок-паттерн:** [боль / POV / «when you…»] + эмодзи → [персонаж] → [формат-штамп «Funny Cartoon /
Animated / No Words»] в ХВОСТЕ. Реальные образцы (live): Oddbods «Sip Happens! ☕ | Oddbods Full Episode |
Funny Cartoons», Larva keyword-tail, Shaun the Sheep front-emoji, Simon's Cat punny gag-phrase; вирусные
phone-addiction: «I Forgot My Phone» 20M/2 нед.
