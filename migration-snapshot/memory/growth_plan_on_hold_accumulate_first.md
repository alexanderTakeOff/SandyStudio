# Growth-план 25 июл — НА УДЕРЖАНИИ до накопления данных

**Решение Директора 2026-07-25:** «данных слишком мало для выводов. Накопим ещё,
хотя бы штук десять, потом начнём вносить коррекции. Пока — только анализ и
починка действительно очевидных ошибок.»

## Режим до порога
- **Копим ~10 точек данных** (дневных замеров / сопоставимых роликов) ПРЕЖДЕ чем
  менять продукт.
- **Разрешено сейчас:** ежедневный анализ (луп сам работает), фиксация наблюдений,
  починка **явных** ошибок (сломанное, очевидно плохое) — без переделки формы под
  недоказанную теорию.
- **Заморожено:** коррекции продукта по гипотезам (форма первых секунд, сериальность
  как «рычаг») — до порога данных.

**Why:** это не осторожность, а прямое следствие [[retention_does_not_explain_reach_yet]] —
контроль 19 июл: Аэропорт (удержание 50%) взял 1220 из ленты, Торговый автомат (58%) — 1
показ. Лента раздала тот, у кого удержание НИЖЕ. Действовать по недоказанному рычагу =
гадание, а каждый отчёт пересказывает шум. Совпадает с доктриной самого скилла
head-of-growth: **EXPLORE перед EXPLOIT** — на малом канале не сходиться на первом шумном
победителе, пока сигнал не перестал быть шумом.

**How to apply:** в дневном отчёте — наблюдения и дельты, НЕ рекомендации-коррекции.
Помечать гипотезы `PENDING`, копить контроль. Предлагать переделку продукта только
после порога ИЛИ по эксперименту с ОДНОЙ переменной.
