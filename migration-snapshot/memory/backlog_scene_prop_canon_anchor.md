# Канон-дрейф пропа внутри сцены — keyframe-as-anchor (ref-only)

**Статус:** ДИСКУССИЯ (2026-07-12), не реализация. Директор согласовал направление **q2**
(ref-only аварийный якорь), НЕ q1 (match-cut соседних шотов того же угла).

## Проблема (пример Директора)
Внутри ОДНОЙ сцены (эскалатор) шот K: маленькая красная кнопка слева. Шот K+1: большая
синяя кнопка справа. Это **не** стилевой дрейф фона — это конкретный **проп родился внутри
сцены, а источника правды у него нет**. Каждый шот честно фантазирует деталь заново.

## Два вкуса (лечатся по-разному)
- **Вкус А — деталь ЕСТЬ в каноне локации**, но генератор её игнорит от шота к шоту.
  Fix = локнутый плейт локации подаётся референсом в КАЖДЫЙ шот сцены. ffmpeg НЕ нужен —
  это проблема анкоринга, не извлечения.
- **Вкус Б — детали НЕТ нигде** (её выдумал первый шот). Источника правды не существует.
  Пример с кнопкой = почти наверняка Б. **Здесь ffmpeg-кадр зарабатывает место.**

## Механизм (ffmpeg — по факту точное извлечение кадра)
`ffmpeg -i in.mp4 -ss <t> -frames:v 1 -q:v 2 frame.jpg` (`-ss` ПОСЛЕ `-i` = точный seek).
Первый APPROVED-шот, где деталь появилась, становится де-факто каноном → вытаскиваем
**чистый** кадр (НЕ последний — последний смазан движением) → промоутим деталь в **референс
сцены** → пиним вперёд как ref-only якорь (при смене угла нельзя как start_image — дерётся
с движением, см. [[anchor_mode_orbit_ref_only]]).

## Системный ход (не костыль)
Инвариант: **любой повторяющийся проп, рождённый в APPROVED-шоте, должен подняться в канон
сцены ОДИН раз, чтобы все следующие шоты его наследовали.** Симптом (кнопка гуляет) вытекает
ровно из отсутствия этого подъёма. Та же форма, что скилл `episode-cast-completeness-check`
(новый-в-серию канон-ассет, рождённый посреди пайплайна, надо зарегистрировать) — только там
каст, здесь пропы/детали локации. ffmpeg-кадр = МЕХАНИЗМ харвеста, не отдельный движок; едет
на уже существующей ref-only ветке (анти-аддитивность — переиспользуем end_image/anchor-плумбинг).

## Риски
1. **Последний кадр = самый уродливый** (моушн-блюр, поза «между», фейд стыка) — брать чистый
   кадр у конца, не буквально N-1.
2. **Поколенческий дрейф** (фотокопия с фотокопии): цепочка K→K+1→K+2 на выходах AI-рендеров
   копит деградацию. Якорить на LOCKED канон, не daisy-chain по рендерам.
3. **Смена угла ломает start_image** → только ref-only ([[anchor_mode_orbit_ref_only]]).
4. **Запекаем дефект**: тянуть кадр ТОЛЬКО из APPROVED-шота, не из raw.
5. **Ground truth**: нужно ПРАВИЛО — первый APPROVED-шот сцены фиксирует локейшн-детали; кто
   ратифицирует подъём в канон.

## Открыто
- **q3** (не отвечено): добро на read-only разведку кода (episode_ref designer, anchor-плумбинг,
  [[backlog_td_vgen_endimage_metadata_gap]]) — есть ли уже подача локейшн-плейта референсом в
  шоты, куда встраивается харвест-кадр. Карта «что есть / чего не хватает» перед любым планом.
